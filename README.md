## 1. 项目概述

**项目名称**：链上存证小助手 (On-Chain Notary Assistant)

**核心目标**：构建一个基于区块链的Web应用，允许用户为任何数字文件（如图片、文档）生成唯一的“数字指纹”，并将该指纹永久地、不可篡改地记录在以太坊测试网上，以实现低成本、高效率的数字版权确权。

**解决的问题**：
- **数据确权**：为数字创作者提供无法伪造的、带有时间戳的“存在性证明”。
- **维权困难**：当发生版权纠纷时，提供可在法庭上作为证据的链上记录。
- **技术门槛**：让非技术用户也能轻松使用区块链技术保护自己的数字资产。

用户浏览器 (前端) <--> 以太坊Sepolia测试网 (区块链)

## 3. 详细实现步骤

### 3.1 第一阶段：智能合约开发 (1-2天)

**目标**：创建并部署存证合约到Sepolia测试网。

**合约功能设计**：
- `notarizeDocument(string documentHash)`: 记录文件哈希和存证者地址
- `verifyDocument(string documentHash)`: 查询指定哈希的存证者
- 事件 `DocumentNotarized`: 存证成功时触发，便于前端监听

**合约核心逻辑**：
```solidity
// 伪代码逻辑
映射关系：文件哈希 => 存证者地址

function 存证(文件哈希) {
    要求：该哈希尚未被存证；
    记录：文件哈希 -> 当前调用者地址；
    触发事件：存证成功(调用者, 文件哈希, 时间戳)；
}

function 验证(文件哈希) 视图函数 returns (地址) {
    返回：该哈希对应的存证者地址（如无则返回零地址）；
}

部署步骤：

在Remix IDE中编写合约代码

使用Solidity编译器编译合约（选择版本0.8.0+）

连接MetaMask（确保切换到Sepolia测试网）

部署合约，获取合约地址

在Etherscan上验证合约（可选但推荐）

核心功能模块：

3.2.1 钱包连接模块
```javascript
// 伪代码
async function 连接钱包() {
    if (检测到MetaMask) {
        创建Ethers Provider；
        获取Signer（当前用户）；
        连接合约实例；
        更新UI：显示已连接；
    } else {
        提示用户安装MetaMask；
    }
}
```

3.2.2 文件哈希计算模块
```javascript
// 伪代码
async function 计算文件哈希(文件对象) {
    将文件转换为ArrayBuffer；
    使用 crypto.subtle.digest('SHA-256') 计算哈希；
    将结果转换为十六进制字符串；
    在UI中显示哈希值；
    启用 "开始存证" 按钮；
}
```

3.2.3 链上存证模块
```javascript
// 伪代码
async function 执行存证(文件哈希) {
    try {
        调用合约的 notarizeDocument 方法；
        显示交易哈希（用户可点击在 Etherscan 查看）；
        等待交易确认（1-3 个区块）；
        显示存证成功信息（区块号、时间戳）；
    } catch (错误) {
        显示错误信息（如用户拒绝交易、Gas费不足等）；
    }
}
```

3.2.4 存证验证模块
```javascript
// 伪代码
async function 验证存证(文件哈希) {
    调用合约的 verifyDocument 视图函数；
    if (返回地址 != 零地址) {
        显示 "该文件已由 [地址] 在 [时间] 存证"；
    } else {
        显示 "未找到该文件的存证记录"；
    }
}
```
### 3.3 第三阶段：集成测试与部署 (1-2天)
测试流程：

- 获取 Sepolia 测试 ETH（通过水龙头）。
- 本地测试完整流程：

  2. 选择测试文件并计算哈希。
  3. 执行存证交易。
  4. 验证存证记录。
- 测试边界情况：

  - 验证不存在的哈希。

2. 使用 Vercel 连接 GitHub 仓库。
3. 一键部署，获取在线访问链接。

## 5. 关键注意事项
### 5.1 安全考虑
- 隐私保护：文件本身始终留在用户本地，只有哈希值上链。
- Gas费用：明确告知用户测试网交易免费，但主网需要真实ETH。
- 错误处理：全面处理用户拒绝交易、网络错误等场景。

### 5.2 用户体验优化
- 交易状态实时反馈。
- 提供Etherscan交易链接。
- 加载状态提示。
- 移动端兼容性考虑。

### 5.3 扩展可能性
- 支持IPFS存储文件元数据。
- 添加批量存证功能。
- 实现存证历史记录查看。
- 支持其他文件类型特定功能。
